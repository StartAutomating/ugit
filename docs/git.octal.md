Get-GitOctal
------------

### Synopsis
Gets Git Octal strings

---

### Description

Gets Git Octal strings as the current output encoding.

---

### Parameters
#### **OctalString**
An octal string

|Type      |Required|Position|PipelineInput        |
|----------|--------|--------|---------------------|
|`[String]`|false   |1       |true (ByPropertyName)|

---

### Syntax
```PowerShell
Get-GitOctal [[-OctalString] <String>] [<CommonParameters>]
```
